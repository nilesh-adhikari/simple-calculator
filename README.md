# Simple Calculator 🧮

A simple calculator I made using Python and Tkinter.

This was one of my first proper GUI projects. I built it while learning Tkinter and wanted to understand how buttons, Entry widgets, functions and frames work together.

## What it can do

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal numbers
- Delete last character
- Clear the whole input
- Display the result in the calculator window

## Built With

- Python
- Tkinter

## What I learned

While making this, I learned how to:

- Create a GUI using Tkinter
- Use `Entry` widgets to take input
- Connect buttons to functions
- Use `lambda` with button commands
- Arrange widgets using `grid()`
- Work with strings and numbers
- Build basic calculator logic

It's a pretty simple project, but it helped me understand Tkinter a lot better.
